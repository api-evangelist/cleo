# Cleo

> Cleo is an AI-powered personal finance assistant delivered as a chat interface inside
> iOS and Android apps. It helps consumers budget, track spending across linked bank
> accounts, set savings goals, and reach features such as Cleo Wallet (savings), Cleo
> Cover (cash advance) and Cleo Builder (credit building). Bank connectivity is
> read-only and brokered through Plaid.

## What an agent needs to know first

Cleo publishes **no public API**. There is no OpenAPI, no GraphQL endpoint, no MCP
server, no A2A agent card, no webhook catalogue and no developer portal an outside
integrator can reach. Cleo is consumed as an end-user mobile product, not as a
programmable service. Do not attempt to construct calls against it.

Two things Cleo does serve publicly, and neither is an integration surface:

- An RFC 8414 OAuth 2.0 Authorization Server Metadata document at
  https://www.meetcleo.com/.well-known/oauth-authorization-server. Its
  authorization_endpoint redirects to an internal admin sign-in, so it documents an
  internal deployment, not third-party access.
- An API-documentation host, https://api-docs.meetcleo.com, which redirects every path
  to Google Workspace SAML sign-in. It is employee-only.
